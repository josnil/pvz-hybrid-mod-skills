# 新建植物 Mod —— 逐项打勾清单

> 用法：把本文件复制成 `ModWorkspace/_清单_<新植物名>.md`，边做边打勾。
> 对应主流程见 `SKILL.md` §3 的 12 步。

## A. 需求（Step 0）—— 缺任何一项后面必返工

- [ ] 复用哪个内置植物？（中文名 + 英文 key，中文名要查 `Asset/Translate/Translate.csv`）
- [ ] 阳光费用 `cost` / 冷却 `packetCooldown` / 卡类型 `PACKET_TYPE` / 血量 `hitpoints`
- [ ] 要不要**直接种在空地**？（要 ⇒ 卡片内联 packet override）
- [ ] 要不要**进选卡界面 / 图鉴**？（要 ⇒ 必须告知"会变成正常金卡，随机取卡逻辑会给出它"）
- [ ] 要不要**换外观**？（A 官方 reanim / B 自制 / C 复用原版）
- [ ] 有没有**纯数据做不到**的玩法？（概率 / 连射 / 真随机 / 逐颗）⇒ 若有，**先把取值跟用户确认**

## B. 建包（Step 1–3）

- [ ] `cp build_plant_super_gatling.py → build_plant_<新名>.py`
- [ ] 改 4 个主键并且**全部同一个字符串**：
      `BUILD_DIR` / `MOD_NAME` / `MOD_ID` / **`CHAR_KEY`**
- [ ] `CHAR_KEY` 四处同名已核对：
      `Scene/<Key>.tscn`、`Sprite/<Key>.tscn`、`Config/TowerDefensePlant<Key>.tres`、`Cards/<Key>.tres`
- [ ] `characterConfig.name == packet.saveKey == <Key>`
- [ ] `provides` 三键 = `Character` / `CharacterSprite` / `Packet`，**值都是 `<Key>`**
- [ ] `unlockCheckList = []`（或 `XWModProgressUnlockCondition`）
- [ ] `resources` 列表 = 全部非忽略文件、`OrdinalIgnoreCase` 升序、**含 `Runtime/ModAssembly.dll`**
- [ ] 包内**没有** `.cs` / `.scn` / `.res` / 内嵌 GDScript
- [ ] 包内自引用**全是相对路径**（Sprite 场景在 5 段目录 ⇒ **5 个 `../`**）
- [ ] 指向游戏自带资源的**全是 `res://`**

## C. 关键三处（漏一处就静默失败）

- [ ] **角色场景显式声明** `ComponentSet = ExtResource(...)`，且在 `script` **之前**，值是 `./<Key>ComponentSet.tres`
- [ ] 包内 `ComponentSet` 的 `ParentSet` 指向内置集，`Components` **只加 1 个**发射定义
- [ ] 包内组件集 `spritePath` 指向 `SpriteGroup/TransformPoint/<精灵>/Head`（若用头身分离）
- [ ] **`.dat` 与 `.tres` 的 `events` 表都有 `{"Command":"fire","Argument":""}`**，且帧号 = 推导出的发射帧
- [ ] `fireAnimeClips` / `spliceIdleAnimeClips` / `isSpliceSprite` / `firePosMarkerPaths` 都指对
- [ ] `firePosMarkerPaths` 指向的节点**真的是 `Marker2D`**（不是 `AdobeAnimateSlot`）

## D. 发射配置

- [ ] 纯数据路线：扇形 ⇒ `fireNum=1` + `fireNumAtOnce=true` + N 条 config
- [ ] 插件逐颗路线：**只留 1 条 config（`dir=0`）** + `fireNum=1`、**不写 `fireNumAtOnce`**
- [ ] `PROJECTILE_NAME` / `speed` / `dir` 已核对（`dir` 单位是度，0 = 向右；朝向自动镜像不用管）

## E. 外观（若换）

- [ ] 走 A：`.cache/build_official_skin.py` 已跑，`skin_params.json` 已更新
- [ ] 走 B：`build_atlas2.py → build_dat.py → build_tres.py` **按序全跑**过
- [ ] 走 B：`scale` 有**显式断言**（不是 1.0 也不是二次乘）
- [ ] `offset` = `−(40,40)`（根与 Head 相同）、`Head.position=(0,0)`（**死值/占位**：`UpdateChild()` 每帧覆盖它）
- [ ] 要微调头位改的是 **`Head.offset`**（不是 `Head.position`）；跨体格拼装必须**重标定**
- [ ] `insertLayerId == max(body 真实贴图层) + 1`（**排除只用 locator 占位的控制轨**）
- [ ] clip = `BodyIdle` / `HeadIdle` / `HeadFire`，且 **`HeadFire` 含射击段 + 大招段**
- [ ] `Marker2D`（炮口）位置已按新素材重算
- [ ] 生成器 + `sprite_scene_tscn()` **一起改**（否则重跑即回退）

## F. 数值（若改）

- [ ] `cost` / `costRise` / `costNight` / `packetCooldown` 写在**植物 Config**
- [ ] `type` 写在**卡片**
- [ ] `hitpoints` 写在**植物 Config**，位置紧跟 `name`（类声明顺序）
- [ ] 直接种空地：卡片内联 override，**只写 `coverCanDirectPlant = true`**，属性名是 `override`（不是 `_override`）

## G. 插件（若需要）

- [ ] `runtimeAssembly = "Runtime/ModAssembly.dll"`（**字面量**）、`runtimeApiVersion = 1`
- [ ] `runtimeAssemblyPolicy = "optional"`（新 Mod 从它起步）
- [ ] 三个回调**全 try/catch**，绝不抛
- [ ] **每条出错路径各一个「已报告」标志**，不共用
- [ ] `Runtime/` 下**只有 `ModAssembly.dll`**（无 `.pdb` / `.deps.json`）
- [ ] csproj 有 `<Compile Remove="check_*.cs" />`
- [ ] 用 `OnFireReady`（无需去抖）而不是 `OnFireVolley`
- [ ] 逐颗发射前已确认数据侧只有 **1 条 config**
- [ ] 已设 `fire.fireEventName = "modfire"` 掐掉原版开火链（且 `events` 里没有对应 `fire` 条目）
- [ ] 自定义皮肤 ⇒ 已设 `forceLocalRender = true` + `forceCpuPoseRender = true`，**每 N 帧全树扫描幂等**
- [ ] 长卡顿保护（`gap > 400ms` ⇒ 时间轴整体后移）
- [ ] 单帧上限（`MaxPeasPerFrame`）

## H. 闸门（Step 10）—— 全部必须绿

- [ ] 生成器 `self_check()` 通过
- [ ] `check_plant_<名>.py` FAIL = 0
- [ ] `run_gates_plant.py` **remake 构建** PASS/FAIL = 0
- [ ] `run_gates_plant.py` **console 构建** PASS/FAIL = 0
- [ ] `check_modloader_gates.py` FAIL = 0
- [ ] `check_project_folder.py` FAIL = 0
- [ ] `check_sgp_idem_single.py`（幂等）全一致
- [ ] `verify_official_skin.py` FAIL = 0 且 `--negative` **全部报错**
- [ ] 三处字节一致：工作区构建目录 == Mods 镜像 == pmod 内部

## I. 装机与验收（Step 11–12）

- [ ] `Mods\<MOD_NAME>.pmod` 已生成，sha256 与 `dist/` 一致
- [ ] `Mods\<MOD_NAME>\` 工程镜像已更新
- [ ] `enabled_mods.json` 含自己的 `manifest.id`
- [ ] 读 `logs\godot.log`：`package applied: <modid>; … rollbackBlocked=False`
- [ ] **逐项实机确认**：动画动/头身接缝/炮口/出膛点/命中/图鉴与选卡显示/费用冷却/大招观感
- [ ] 交付说明如实标注：翻译仅编辑器可见；联机因真随机不同步；进金卡池的副作用
